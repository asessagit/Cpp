# 📌 Objetivo do Repositório

Este repositório reúne exemplos básicos em C++ para estudo e prática.
O foco principal é entender a fundo como o software pode manipular a memória, explorando conceitos como:

Controle manual de variáveis e ponteiros

Estruturas de controle (if, while, for)

Vetores e alocação estática

Compilação automatizada com Makefile

A ideia é usar C++ como ferramenta para compreender como os programas interagem diretamente com os recursos da máquina, oferecendo maior controle e desempenho em comparação com linguagens de mais alto nível.
